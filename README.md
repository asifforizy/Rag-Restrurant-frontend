# RAG Restaurant Frontend

This is a frontend application built to test and demonstrate a Retrieval-Augmented Generation (RAG) backend for restaurant-related queries.

It provides a simple interface where users can ask questions about restaurants, dishes, services, or menu-related topics, and receive responses generated using the backend's retrieval and AI pipeline.

## Live Demo

Visit the app here:
https://rag-restrurant-frontend.vercel.app/

## Purpose

This project is mainly for testing the RAG backend and validating:

- frontend-to-backend API communication
- response quality from the RAG system
- user experience for AI-powered restaurant queries
- quick local and deployment testing before full product integration

## Features

- Simple chat-style interaction
- Restaurant-related question input
- Backend-powered RAG responses
- Easy testing environment for AI retrieval workflows
- Deployed on Vercel for quick access

## Tech Stack

- Next.js
- React
- TypeScript
- CSS
- Vercel

## Project Goals

This frontend is not a production-grade product by itself. It is designed as a testing UI for the RAG backend, helping developers verify whether the backend can:

1. receive user queries
2. retrieve relevant restaurant information
3. generate useful answers
4. return results in a friendly frontend experience
